**Discover the World**

- by Azamas Alexander Krause, Leila Akdad and Paula Makowe

We created Discover the World as a little geography challenge where you have to figure out which country we’re thinking of.
You get 6 guesses to find the mystery country, with a new hint after every incorrect guess. 
If that’s not enough, you can also ask our AI geography assistant yes-or-no questions to narrow things down. 
And don’t worry, those questions don’t count as guesses!
Once you’re done playing, you can check out your personal stats and see how well you did. 
Maybe you’ll discover that you’re better at geography than you thought. ;)

**How to Run the Game**

1. Get everything ready

Make sure all project files are in the same folder, including the Python files and the three image assets:

* background_welcome.png
* background_play.png
* weltkugel.png

The project also needs the packages listed in requirements.txt.

2. Start the game

Open the project folder in your terminal and run:
streamlit run main.py

3. Before playing

* Go to the Play page.
* Enter your Uni Osnabrück AI API key in the sidebar. You can get one at ai-keys.uni-osnabrueck.de.
* Start guessing!

Your API key stays saved during your current session, so you don’t have to enter it again when switching between pages.
Have fun and good luck finding all those countries!
